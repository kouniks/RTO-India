Deploy on GitHub Pages in 60 Seconds

Zero build step required — works directly as a single index.html file

This application is architected as a self-contained HTML5 application with both a built-in high-precision RTO dataset and a live CORS-enabled Wikipedia MediaWiki API parser.

Step 1: Save this file as index.html

Save the code in a new folder and push it to a GitHub repository:

git init
git add index.html
git commit -m "Add interactive India RTO Two-Way Map & HSRP Explorer"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/india-rto-map.git
git push -u origin main
Step 2: Enable GitHub Pages
  1. Open your repository on GitHub and click Settings → Pages.
  2. Under Build and deployment → Source, select Deploy from a branch.
  3. Select branch main and folder / (root), then click Save.
  4. Your live interactive map will be published at https://YOUR-USERNAME.github.io/india-rto-map/!
Optional: Export Standalone JSON / CSV

Switch to the Data Table & Export tab at the top to download indian-rto-database.json or indian-rto-database.csv containing all extracted Wikipedia RTO records with geocoded coordinates.
